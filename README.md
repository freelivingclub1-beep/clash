# CLASH

A turn-based 3v3 card basketball game for mobile.

40 spots on the floor. Three collected cards. Every beat, the offense picks where
to go and what to do — advance, shoot, pass — and the defense predicts it and
answers with a contest, block, or steal. Card stats set the math. The player still
has to read the defender and hit the shot meter.

No live dragging. Two taps per beat, five seconds to decide.

See **[GAME_DESIGN.md](GAME_DESIGN.md)** for the full design: floor layout, action
economy, the prediction/tell system, shot meter formulas, carom and rebound tables,
card stats and skills.
